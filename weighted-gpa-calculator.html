Weighted vs. unweighted GPA

An unweighted GPA treats every class the same on a 4.0 scale. A weighted GPA gives extra points for harder classes, so students in honors, AP or IB courses can earn a GPA above 4.0.

This calculator adds 0.5 points for honors and 1.0 point for AP/IB to each passing grade. A grade of F gets no bonus.

Weighted GPA = total weighted quality points ÷ total credits

Example: an A in a regular 3-credit class is 4.0. An A- in a 3-credit honors class is 3.7 + 0.5 = 4.2. A B+ in a 4-credit AP class is 3.3 + 1.0 = 4.3. A B in a regular 3-credit class is 3.0. The weighted points are 12 + 12.6 + 17.2 + 9 = 50.8 over 13 credits, so the weighted GPA is 3.91. The same classes give an unweighted GPA of 3.48.

Frequently asked questions

Does every school weight GPA the same way?

No. Some schools add 0.5 for honors and 1.0 for AP, some add different amounts, and some do not weight at all. Check your school's handbook. This is an estimate.

Will colleges use my weighted GPA?

Many colleges recalculate GPA using their own method, often unweighted or based on core classes only. Ask the admissions office what they use.

What grade scale does this use?

A+ and A are 4.0, A- is 3.7, B+ is 3.3, B is 3.0, and so on down to F at 0.0, the same scale as our GPA calculator.
